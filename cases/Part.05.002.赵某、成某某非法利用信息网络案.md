## 二、案情简介

### （一）作案时间与人员
- **时间**：2023年至2024年1月间
- **被告人**：赵某（北京市海淀区）、成某某（广东省）
- **联络方式**：伙同境外犯罪分子，使用加密通讯工具 Telegram（俗称"电报"）联络

### （二）犯罪行为
1. **获取信息**：通过 Telegram 访问已泄露的公民个人信息数据库，收买、非法获取公民个人信息数据；
2. **担任管理员**：在用于"开盒"的 Telegram "A"频道、"B"群组中担任管理员；
3. **编辑发布**：将某虚拟偶像团体的配音演员及"粉丝"的户籍、手机号、行踪轨迹信息、健康生理信息等个人隐私信息，混合编辑成针对个人的侮辱谩骂、造谣诽谤的违法犯罪信息文案；
4. **诱导网暴**：在频道、群组中发布上述文案，诱导关注者、群组成员以电话、短信轰炸等方式对被侵害人开展侮辱、谩骂。

### （三）涉案数据规模

| 项目 | 数量 |
|:---|:---|
| 非法获取公民信息 | 900余组 |
| "A"频道发布非法文案 | 600余组 |
| "A"频道成员 | 3万余人 |
| 文案总查看量 | 1000万余次 |
| 总评论量 | 1.9万余条 |
| "B"群组成员 | 5千余人 |

### （四）危害后果
- 非法信息从境外隐秘网络空间传播至境内网络空间；
- 不知情的网民对被侵害人线下跟踪骚扰，对其社交媒体账户跟帖辱骂；
- 被侵害人直接面对网络暴力压力与现实侵害风险，严重危害正常生活、工作、人身财产安全；
- **2名被侵害人因此罹患抑郁症**。

---

## 三、检察履职要点

### （一）引导侦查取证
- 会同公安机关通过信息化调查手段锁定境内犯罪嫌疑人；
- 依托电子数据审查室开展实质性审查；
- 引导公安机关、鉴定机构对涉案频道、群组进行**全量数据固定**；
- 查明频道、群组数据关联关系，审查分析非法文案数量、观看量、评论量、评论内容等数据，客观认定不法行为及危害后果。

### （二）深化协同履职
- 检察机关实地前往被侵害人所在地调查取证；
- 依法向网信、工信部门及境内网络社交媒体平台转递线索；
- 及时封禁涉及网络暴力的社交媒体账户，有效遏制关联网络暴力信息的蔓延。

### （三）加强源头治理
- 联合工信、网信部门、公安机关深挖涉案关联犯罪线索；
- 锁定并抓获**5名关联犯罪嫌疑人**；
- 形成**集群打击、源头治理**效果。

- **赵某**：犯非法利用信息网络罪，判处有期徒刑**一年六个月**，罚金人民币**一万元**；

## 六、实务要点与启示

1. **罪名适用**：本案以**非法利用信息网络罪**（《刑法》第287条之一）定罪处罚，而非侵犯公民个人信息罪或侮辱罪、诽谤罪，体现了对"开盒"行为中"利用信息网络发布违法犯罪信息"这一核心环节的精准打击。

2. **跨境协作特征**：犯罪行为具有典型的境内外勾结特征，利用境外通讯工具（Telegram）和已泄露数据库实施犯罪，检察机关通过信息化手段锁定境内嫌疑人是关键突破点。

3. **电子数据固定**："全量数据固定"是认定本案危害后果的基础，包括文案数量、成员规模、查看量、评论量等数据的客观化认定，为量刑提供支撑。

4. **"开盒"行为的刑法规制**：本案明确了将个人隐私信息编辑为侮辱谩骂、造谣诽谤文案并诱导网暴的行为，属于非法利用信息网络罪中的"发布违法犯罪信息"，为同类案件办理提供了参考。

5. **被害人保护**：检察机关实地调查取证，关注网络暴力对被害人造成的现实危害（如抑郁症），体现了对被害人人身权益的综合保护。
